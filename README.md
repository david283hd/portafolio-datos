# Portafolio de Datos — David Anastacio

Análisis de datos aplicado a cobranzas: **Power BI, SQL (MySQL), Python y reportes HTML automatizados**.

👉 **Ver el portafolio:** https://david283hd.github.io/portafolio-datos/

## Qué hay aquí

| Sección | Contenido |
|---|---|
| ★ Destacado | *Desempeño de gestoras* (Power BI): captura real + versión interactiva para explorar por gestora |
| 1 · Fundamentos | Dashboards de práctica (Power BI, Looker Studio) con autocrítica y un rediseño |
| 2 · Primer reporte de negocio | *Campo Cobranzas*: reporte Power BI de 7 páginas para gestión en campo |
| 3 · Más allá de Power BI | Resumen ejecutivo diario por SQL + Python + HTML,  |
| 4 · Proyectar y automatizar | Procesos programados, proyecciones con validación hacia atrás, carga a central de riesgo |

## Confidencialidad

- Las capturas reales tienen pixelados nombres de personas, IDs de clientes y ubicaciones.
- Las demos interactivas usan **datos simulados**.
- No se incluyen bases, consultas ni credenciales de la empresa.

## Técnico

Sitio estático: un solo `index.html` (HTML, CSS y JavaScript sin librerías) + imágenes en `img/`.
Funciona abriéndolo directo en el navegador, sin conexión, y se publica con GitHub Pages.

## Demos

Tres reportes reconstruidos con datos simulados: cobranza del día en vivo, proyección de cierre de mes y probabilidad de pago por segmento.
